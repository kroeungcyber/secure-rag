# NGO Pilot — real-work test of secure-rag

Date: 2026-08-19
Status: **Approved (defaults 5–8) — awaiting user inputs for decisions 1–4**

## One-liner

Run `secure-rag` in a real NGO for a bounded period to prove the "real-work
tested" success criterion — does it actually cut time-to-answer and improve
access to institutional knowledge, without data leaving the organisation?

## Goal

Produce hard evidence for the portfolio and admissions case: a before/after
measurement, a grounded-answer accuracy spot-check, and an honest go/no-go —
not a demo, a deployment.

## Non-goals

- No cloud services, no SaaS embeddings, no per-token API (local-first stays).
- No new features during the pilot — scope-freeze the shipped build.
- Not a vendor/enterprise rollout; this is a single-office validation.

## Key decisions (verify each)

1. **Deployment target** — which NGO / office / team? (yours to name)
2. **Hardware + model** — the decisive faithfulness lever. `llama3.2:3b`
   (2 GB) runs on ~8 GB RAM but is unreliable; `gemma4` (9.6 GB) is faithful
   but wants ~16 GB+ RAM. Pick the machine, then the model it can hold.
3. **Corpus** — which real documents (SOPs, policies, donor FAQ), roughly how
   many, and a data-protection review *before* ingest (PII redaction is regex,
   not NER).
4. **Users + roles** — how many people, split across `admin`/`staff`/`field`.
5. **Duration** — suggested 2–4 weeks.
6. **Success metrics** — e.g. time-to-answer before/after, answer-usefulness
   rating, query volume, citation-accuracy spot-checks, and a "would you keep
   using it?" survey.
7. **Governance** — `PROGRAM.md`: commands OFF, path/URL whitelist limited to
   the corpus, `redact_pii: true`, audit log reviewed weekly, data-protection
   officer signs off.
8. **Go/no-go** — pre-agreed threshold (e.g. "X% of testers rate answers useful
   AND no breach/leak event AND time-to-answer down") to continue vs roll back.

## Success = the artifact

A one-page pilot report (metrics + verdict + what broke) that slots into the
portfolio and admissions project case as the "real-work tested" evidence.
